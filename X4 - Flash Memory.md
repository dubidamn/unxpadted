#### **`Format & Aturan Main`** **`X4 - Flash Memory`**

**`Peserta:`**  
`2 wakil per kelas (2v2), submit jawaban tim secara kolektif di XPAD`

**`Alur permainan — 2 fase:`**

**`Phase 1 — Tayangan (Flash Phase):`**

1. `4 gambar/video ditayangkan berurutan di main screen, terlihat bersamaan oleh kedua tim`  
2. `Setiap media tampil 5–10 detik, tanpa jeda, tanpa bisa diulang`  
3. `Tidak ada catat-mencatat, peserta murni mengandalkan ingatan visual`

**`Phase 2 — Jawab (Recall Phase):`**

1. `Setelah 4 media selesai, sistem menampilkan serangkaian soal terkait — bisa beberapa soal per media (tebak warna, jenis objek, jumlah, urutan kemunculan, dst.)`  
2. `Kedua tim mengisi jawaban menggunakan AdaptoX di XPAD secepat mungkin lalu submit (mirip format speedrun)`  
3. `Sistem mencatat waktu submit dan jumlah jawaban benar`

**`Penentuan pemenang:`**

* `Kriteria utama: jumlah jawaban benar terbanyak`  
* `Tie-breaker: total waktu submit tercepat menang`

**`Phase 1 — Tayangan (Flash Phase):`**

| `Media` | `Jenis` | `Isi Konten` | `Durasi Tayang` |
| ----- | ----- | ----- | ----- |
| `1` | `Gambar` | `Apel merah di atas meja kayu` | `6 detik` |
| `2` | `Video` | `Bola basket oranye memantul 3 kali di lantai` | `8 detik` |
| `3` | `Gambar` | `Mobil sedan biru terparkir depan gedung` | `5 detik` |
| `4` | `Video` | `Kucing hitam berjalan melewati pagar putih` | `10 detik` |

**`Phase 2 — Jawab (Recall Phase):`**

| `No` | `Media` | `Soal` | `Jawaban` |
| :---- | ----- | ----- | ----- |
| `1` | `1` | `Buah apa yang muncul di gambar 1?` | `Apel` |
| `2` | `1` | `Apa warna buah tersebut?` | `Merah` |
| `3` | `2` | `Apa warna bola pada video ke-2?` | `Oranye` |
| `4` | `2` | `Berapa kali bola memantul di video ke-2?` | `3 kali` |
| `5` | `3` | `Apa warna mobil pada gambar ke-3?` | `Biru` |
| `6` | `3` | `Jenis kendaraan apa yang tampil di gambar ke-3?` | `Mobil sedan` |
| `7` | `4` | `Apa warna kucing pada video ke-4?` | `Hitam` |
| `8` | `4` | `Objek apa yang dilewati kucing tersebut?` | `Pagar (putih)` |
| `9` | `1–4` | `Sebutkan urutan media dari 1–4 (buah → bola → mobil → kucing)` | `Sesuai urutan tayang` |

**`Pola ini tinggal diganti temanya per match (buah/hewan/kendaraan/warna/angka)`** `supaya soal tidak mudah ditebak peserta yang sudah pernah nonton match sebelumnya.`
